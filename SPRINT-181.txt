WHAT CHANGED

  1. Five plain <table> elements on /how-golf-launch-monitors-work/ and
     /average-swing-speed-by-age/ had NO class and NO CSS — 180 inline styles
     were the only thing holding them up. Now .art-table.
     Checks made BEFORE converting, because guessing here would have been
     visible on live pages:
       - .cmp-table was NOT reused. It pads 12px 16px with a green header and
         zebra stripes; these are tighter in-prose tables at 8px 12px. Folding
         them in would have restyled all five.
       - the bold first column is PER TABLE (3 of 5 use it, 2 do not), so it is
         a --keycol modifier. A blanket td:first-child rule would have bolded
         27 cells instead of 15.
       - the unstyled <tr> in each table is always the LAST one — no rule under
         the final row. Reproduced with tbody tr:not(:last-child).
     Every value in the new CSS is lifted from the inline it replaces. This is
     not a redesign.

  2. 194 <span style="opacity:.55"> → <span class="cmp-delta">.
     One declaration that was repeated 194 times.

  3. scripts/validate-inline-styles.ts (NEW) — the durable part.
     Counts literal style="" across src/ and fails if the total goes UP.
     CEILING = 1371. Lower it when a sprint drains more; never raise it.
     Dynamic style={...} bound to data is not counted — that cannot be a class.
     PROVEN: adding one probe style made it fail with "1372 ... ceiling is 1371".

  RESULT: 1,745 → 1,371 (-374, -21%).  articles.ts: 393 → 19.

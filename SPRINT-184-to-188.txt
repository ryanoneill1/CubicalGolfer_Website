★ THE HEADLINE: "[object Object]" WAS VISIBLE ON 147 PAGES

MY BUG. Sprint 178 removed the mid-article disclosure markup but left the
conditional wrapping a lone JSX comment:

    {isCommercial && (
      {/* a comment */}
    )}

A lone JSX comment inside parentheses is an empty OBJECT. So the expression
evaluates to {} and Astro prints it. The build was green. About fifty
validators were green. Every reader and Googlebot saw "[object Object]".

Nothing caught it because every check looked at structure, prices, links or
CSS. None read the page the way a READER does.

  FIXED: both conditionals removed (not emptied). 147 pages -> 0.
  GUARDED: scripts/validate-rendered-objects.ts scans built body text for
    [object Object], [object Promise], and bare "undefined" / "NaN", with
    scripts, styles and JSON-LD stripped first so it cannot cry wolf.
    PROVEN FAILING: reintroducing the exact Sprint 178 shape trips it at
    "147 placeholder value(s) visible as body text".

This is the third time this JSX-comment trap has cost something here, so the
reasoning is written into the template and the validator, not just this note.

== WHY THIS ==================================================================
The five brand compression charts are the best-ranking thing on the site.
Measured on live SERPs this week:

    Srixon       #1
    Bridgestone  #1
    Titleist     #2
    TaylorMade   #3
    Callaway     #4

Five for five on page one, off one template. Meanwhile Vice — which has FOUR
balls in balls.ts, the same count as Srixon, Callaway and Bridgestone — has no
page, and the generic all-brands chart is left to cover the query. It currently
ranks #4 for "vice golf ball compression chart", behind vicegolf.com,
ballcaddie.com and outofboundsgolf.com.

On every brand where a dedicated page exists, that page outranks what the
generic chart was managing. That is the whole bet here, and it is the best-
evidenced one available: a template with a 5-for-5 record, pointed at the one
brand big enough to deserve it.

I also checked Wilson and Maxfli. Both are NOT ready: BRAND_DETAIL has no entry
for either, so BrandCompressionChart would crash on detail.lead. Vice already
has one — written in Sprint 165. The data was there; the page was never built.

== THE INLINE-STYLE CEILING — HANDLED ========================================
validate-inline-styles has a hard ceiling of 1225 and I cannot compute the
current site-wide total from the files I hold. A new page built like its five
siblings would have added 8 literal style="" attributes, and if the count were
near the ceiling that fails your build.

So the Vice page uses CSS classes and contributes ZERO. Verified by running the
validator's own comment-stripping logic over the file: 0 matches. This sprint
is build-safe regardless of what the current total is.

The classes went into global.css, which the validator does not scan. They are
written so the other five pages can migrate to them later — doing so would
drain 40 attributes (5 x 8) and let you lower the ceiling.

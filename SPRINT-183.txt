A FALSE ALARM, FIXED PROPERLY
The first build after adding the CSS failed: "6 values off the 4pt grid",
naming 10px, 6px, 14px and 17px. All six were inside the COMMENT I had just
written documenting the before/after values — the scanner was reading
"padding:3px 10px -> 3px 12px" as a live declaration.

The wrong fix is to reword the comment. The right one is in the scanner, so
validate-spacing-scale now strips CSS comments before reading declarations.
Without that, every future sprint that documents a spacing change in a comment
fails the build on its own prose, and the check gets muted. Re-verified after
the fix that it still catches a real 13px probe in a component <style> block.
